# Лабораторна робота № 3 — варіант 18

Дослідження хвилеводних та рупорних випромінювачів.

λ = 3,1 см; розкрив 10 × 16 см. Використано апертурну модель TE10 з наближенням плоскої фази.

## Запуск

```bash
pip install numpy scipy matplotlib
python horn18.py
```

Програма розраховує кути половинної потужності (для повної ширини їх потрібно подвоїти), нулі та максимуми бічних пелюсток, створює horn_linear.png і horn_polar.png.
